    Import your Excel

    Drop one or more .xlsx / .xls / .csv files. Sheets and columns are recognised automatically (e.g. “Company Name”, “Round”, “Amount ($M)”, “Lead Investor”, a Crunchbase export…), values are cleaned, and the whole dashboard updates. Files never leave your browser.

    Links must be shared as “anyone with the link”. Some services (often SharePoint) block browser access; if so, download the file and drop it above. To make the whole team see the same file automatically, commit it to data/excel/ and list it in data/sources.json.

    Field reference

    Rules: schema/schema.json · Excel header aliases: schema/import_rules.json · Every row needs a public source_url.
