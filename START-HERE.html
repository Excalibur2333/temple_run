Waco Family Guide: start here

A short, non-technical tour of the new website for spouses and dependents of Baylor faculty. No coding knowledge needed.

What is this?

The Waco Family Guide is a website that puts everything a new faculty family needs in one place: campus benefits, visa help for J-2 family members, schools, health care, everyday services, local churches, and upcoming CGE events.

It has two parts:

  • The public website is what families see. Anyone can open it.
  • The staff admin page is where CGE staff add, change or delete events. It needs a staff code, so only staff can make changes. Changes show up on the public website right away.

Status: this is a draft for review. It is not live yet and has not been published on any Baylor website.

Try it on your own computer (optional)

You don't need to do this to review the site. It's here in case you want to click around with real data.

  1. Install Node.js (free) from nodejs.org. Choose the "LTS" version.
  2. Unzip this folder.
  3. Open Terminal (Mac) or PowerShell (Windows) and go into the backend folder. For example, type cd, a space, drag the backend folder into the window, and press Enter.
  4. Start the site with a staff code of your choice: 
    Mac:      ADMIN_TOKEN=pick-a-long-code npm start
Windows:  $env:ADMIN_TOKEN="pick-a-long-code"; npm start
  5. Open http://localhost:3000 in your browser for the public site, and http://localhost:3000/admin for the staff page.
  6. Close the Terminal window to stop it.

Putting it online

To make it a real Baylor website, send this folder to Baylor ITS or the web team. The README.md file tells them what they need: a server that runs Node.js, a secret staff code, and a web address. Before launch, CGE should review the church list and the resource links.
